ABBAS PARACHA — GITHUB PAGES PORTFOLIO
=======================================

FILES
-----
index.html              Website content and sections
style.css               Dark navy and blue styling
script.js               Mobile navigation and current footer year
photo.jpg               Add your own profile photo with this exact filename
Abbas_Paracha_CV.pdf    Add your own CV PDF with this exact filename

LOCAL PREVIEW
-------------
1. Extract this project ZIP.
2. Add your photo as photo.jpg.
3. Add your résumé PDF as Abbas_Paracha_CV.pdf.
4. Double-click index.html to open it in a browser.

GITHUB PAGES
------------
1. Sign in to GitHub and create a new repository.
2. For a personal site, name it USERNAME.github.io (replace USERNAME with your GitHub username).
   Alternatively, use any repository name for a project site.
3. Upload index.html, style.css, script.js, photo.jpg, and Abbas_Paracha_CV.pdf to the repository's
   root folder. You can also upload README.txt.
4. Open the repository's Settings, then Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and /(root), then save.
7. Wait for the published link shown in Settings > Pages, then open it and test every section.

IMPORTANT
---------
- Keep the photo and PDF filenames exactly as referenced in index.html, or update the links there.
- Use relative paths so the files work on GitHub Pages.
- A public GitHub Pages site is visible to anyone. This project deliberately does not publish your
  CNIC/national identity number. Avoid placing your CNIC on a public portfolio.
- The phone number is included because you requested it. If you prefer not to publish it publicly,
  remove the phone contact item from index.html before uploading.
- Check that all qualifications and skills accurately reflect your background before publishing.
